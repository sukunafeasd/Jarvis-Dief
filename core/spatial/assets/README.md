# Deep Space

`deep-space.png` is an original AI-generated environment texture, not a scientific photograph and not derived from the user's reference image. Generated using the built-in image tool on 2026-10-11. The reference image was used only to interpret the requested subtle panel inclination.

Final prompt:

> Create an original wide photographic-looking deep-space background texture for a desktop AI interface. Asset only, NO interface, no hologram, no panels, no text, no astronaut, no spaceship, no planets, no horizon. Astrophotography aesthetic: sparse sharply resolved small white stars, a faint natural dusty Milky Way filament diagonally across the far upper left and lower right edges, subdued charcoal space with small desaturated burgundy and teal dust filaments. Central 60 percent mostly quiet dark sky for foreground interface readability. Detailed realistic astronomical grain and dust, no artificial glowing orbs, no bokeh, no huge galaxy spirals. Wide 16:9 composition, crisp, restrained exposure.

The runtime uses the texture on a distant plane and adds a real Three.js star field with bounded perspective movement. The bitmap remains available as the non-WebGL fallback. No remote assets are loaded by this environment.
